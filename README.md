# PureFox

**Сетевой аудио-плеер (endpoint) на Luckfox Pico Max / Ultra с поддержкой внешних клоков**

> Это форк [ppy2/PureFox_v2](https://github.com/ppy2/PureFox_v2) (ветка `MAX_6.X`). В нём оставлены только плееры NAA и Scream, вывод звука сделан bit-perfect, а ядро Linux можно выбрать: 6.1 или 5.10. Подробнее — в разделе [Изменения в этом форке](#изменения-в-этом-форке).


## О проекте

PureFox — прошивка для плат **Luckfox Pico** **Max** и **Ultra** на базе Rockchip RV1106, превращающая их в высококачественный сетевой аудио-транспорт с поддержкой:

#### Режим сетевого плеера

- Выход **I2S** (внешнее тактирование EXT / встроенный синтезатор PLL)

- Выход **USB**(UAC2)

#### Режим USB транспорта

- USB(UAC2) в I2S

#### Поддерживаемые стандарты audio

- Поддержка PCM 2ch до 768kHz или PCM 8ch до 192kHz

- Поддержка native DSD (64-512 по USB; до DSD1024 в режиме I2S при MCLK 1024x, со старым драйвером 1.6 — до DSD512)

## Изменения в этом форке

По сравнению с исходным проектом [ppy2/PureFox_v2](https://github.com/ppy2/PureFox_v2):

### Звук

- **Bit-perfect вывод.** Из драйвера I2S убрана программная регулировка громкости — PCM приходит на ЦАП без изменений. Mute сохранён (GPIO mute, автоматический mute, контрол «PCM Playback Switch»). Удалены ползунок громкости в веб-интерфейсе и поддержка энкодера громкости.
- **DSD1024 по I2S** при множителе MCLK 1024x (45.1584 / 49.152 МГц). В режиме USB to I2S максимум остаётся DSD512.
- **Быстрый путь DSD** в драйвере I2S: перестановка слов DSD выполняется в кэшируемом буфере, поэтому некэшируемый DMA-буфер записывается один раз.

### Ядро Linux

На форуме сообщали, что прошивка 1.6 (ядро 5.10) звучит иначе, чем 2.8 (ядро 6.1). Чтобы это можно было сравнить, в прошивке есть три варианта ядра:

| Вариант | Ядро | Драйвер I2S | DSD по I2S | USB to I2S |
| ------- | ---- | ----------- | ---------- | ---------- |
| **6.1** (по умолчанию) | 6.1.118 | этого форка | до DSD1024 | да |
| **5.10** | 5.10.160, ядро и конфигурация PureFox 1.x | этого форка | до DSD1024 | нет |
| **5.10 (old drv)** | 5.10.160-pf16, то же ядро | из PureFox 1.6, с его device tree и настройкой тактирования | до DSD512 | нет |

- **6.1 и 5.10** работают с одним и тем же драйвером I2S (bit-perfect, те же настройки I2S), поэтому они отличаются только ядром.
- **5.10 и 5.10 (old drv)** отличаются только драйвером I2S и device tree. В старом драйвере есть программная регулировка громкости; она стоит на 100 и из веб-интерфейса не меняется, а при 100 PCM передаётся без изменений.
- **Переключение.** Переключатель «Ядро 6.1 | 5.10 | 5.10 (old drv)» на главной странице записывает выбранное ядро и device tree текущего режима I2S в загрузочный раздел, проверяет запись и перезагружает плату. Во время записи не отключайте питание; если запись не удалась, повторите её или перепрошейте плату через RV1106_Toolkit. Из консоли: `/opt/kernel.sh 6.1`, `/opt/kernel.sh 5.10` или `/opt/kernel.sh 1.6` (5.10 со старым драйвером), затем `reboot`; `/opt/kernel.sh` без параметров показывает текущее и выбранное ядро.
- **С ядром 5.10** (с любым драйвером) USB-порт работает только в режиме хоста: выход на USB-ЦАП есть, режим USB to I2S недоступен.
- Выбор ядра сохраняется при онлайн-обновлении.

### Плееры

- **Остались только NAA (HQPlayer) и Scream.** Удалены Roon Ready, Squeezelite, AirPlay (shairport-sync), MPD/upmpdcli, APlayer, APrender, Spotify Connect, Qobuz Connect, Tidal Connect вместе с библиотеками, которые нужны были только им. Образ корневой файловой системы уменьшился примерно с 39 до 20 МБ (с тремя ядрами для [выбора ядра](#ядро-linux) — около 30 МБ).
- **Scream вместо APScream.** Закрытый приёмник APScream заменён открытым приёмником [Scream](https://github.com/duncanthrax/scream) 3.6 (вывод через ALSA). На Windows нужен стандартный драйвер Scream; ASIO-отправитель APScream в режиме AP или TCP не поддерживается. На странице настроек задаются режим (multicast/unicast), multicast-группа, порт, сетевой интерфейс, задержка и устройство ALSA.
- **NAA**: обновлён `networkaudiod`; имя в HQPlayer уникально для каждой платы (имя хоста плюс последние шесть шестнадцатеричных цифр MAC-адреса).
- **Выбранный плеер сохраняется при отключении питания**: выбор сразу записывается во флеш-память.

### Прошивка и обновления

- **Релизы на GitHub.** Сборки прошивки публикуются как [релизы GitHub](https://github.com/fkrutko/PureFox_v2/releases) этого репозитория с номером `2.8.<число коммитов>` (например, 2.8.166).
- **Онлайн-обновление с GitHub.** Кнопка с номером версии в веб-интерфейсе скачивает последний релиз по HTTPS с проверкой сертификата (curl), проверяет контрольные суммы SHA-256 и устанавливает его поверх работающей системы, сохраняя настройки пользователя (выход, настройки I2S и Scream, пароль и т. д.). Прошивается выбранное ядро и только если оно изменилось; выбор ядра сохраняется. Файлы с luckfox.puredsd.ru больше не загружаются.

### Сборка

- `./release.sh` собирает текущий коммит локально и публикует его как последний релиз на GitHub (нужен `gh`). `./build.sh` только собирает.
- Собираются три ядра: 6.1 (основное, в `boot.img`) и два варианта 5.10 (пакеты `linux510` и `linux510-pf16`); их zImage и device tree лежат в `/data/boot/<вариант>/`.
- Сборка работает на хостах с GCC 15 (например, Fedora 43); Buildroot использует ccache.

## Прошивка

### Скачивание

Последняя прошивка этого форка — на [странице релизов](https://github.com/fkrutko/PureFox_v2/releases/latest): `PureFox-<версия>.zip` — образ для прошивки через USB.

Прошивка исходного проекта (со всеми плеерами): [MEGA](https://mega.nz/folder/jhJzXZKJ#Y6YbHsS9xCfJL4TKOVeQ4Q), [Яндекс.Диск](https://disk.yandex.ru/d/g8tOCR7uFATj5Q).

### Установка (через USB)

1. Установите драйверы с [Luckfox Wiki](https://wiki.luckfox.com/Luckfox-Pico-RV1106/Downloads)
2. Запустите [RV1106_Toolkit.exe](https://mega.nz/file/ndFiCATS#CG5lF0Nz7JWhmoyrECxeIQDIw3iS5Lv3PZq-MIzJa9c) от имени администратора, выберите **rv1106**
3. Зажмите кнопку **BOOT** на плате и подключите USB
4. Дождитесь появления **Maskrom** в программе
5. Распакуйте архив прошивки, затем выберите Download → USB → Search Path → папка с прошивкой
6. Отметьте все файлы и нажмите **Download**
7. После **Download done** подождите 1 минуту, затем отключите плату

### Веб-интерфейс

После загрузки устройство доступно по адресу `http://purefox/` или по IP. Если домашний DNS не разрешает короткие имена, используйте mDNS-адрес `http://purefox.local/`.
Веб интерфейс поддерживает автоматическое переключение языков (английский, русский, китайский, немецкий, французский).
Лишние кнопки плееров можно скрывать свайпом влево.
Нижняя кнопка с номером версии устанавливает последний релиз с GitHub (онлайн-обновление).
Переключатель «Ядро 6.1 | 5.10 | 5.10 (old drv)» выбирает ядро; плата перезагружается.

Разрешён вход по SSH
логин `root`, пароль: `purefox`.

## Режимы работы

### I2S

- **EXT** — внешнее тактирование от мастер-клока
- **PLL** — синтезатор частоты RV1106. Качество внутреннего PLL на удивление очень высокое. По многим субъективным тестам аудио экспертов звучание внутреннего PLL не уступает звучанию дорогих внешних генераторов.

<img title="" src="images/2026-05-24-10-02-10-image.png" alt="" width="389">

Настройки меню I2S задаются в веб-интерфейсе (страница «Настройки I2S») и позволяют сконфигурировать I2S-выход под конкретный ЦАП:

- **Mode (Режим)** — `PLL` / `EXT`:
  - `PLL` — тактирование от внутреннего синтезатора RV1106 (MCLK работает как **OUTPUT**).
  - `EXT` — внешнее тактирование от мастер-клока (MCLK работает как **INPUT**).
- **Output Mode (Вариант выхода)** — `STD` / `8CH` / `L/R` / `±L/±R`:
  - `STD` — стандартный 2-канальный выход.
  - `8CH` — 8-канальный режим (PCM до 192 kHz).
  - `L/R` — режим дуал-моно.
  - `±L/±R` — дуал-моно с балансным выходом.
- **MCLK** — `512` / `1024` (коэффициент умножения мастер-клока).
- **PCM Swap** — `OFF` / `ON` — инверсия порядка каналов для PCM.
- **DSD Swap** — `OFF` / `ON` — инверсия физических каналов для DSD.
- **44/48 Swap** — `OFF` / `ON` — смена порядка частотных доменов (44.1 / 48 кГц).

> **Внимание:** выход MCLK в режимах PLL и EXT имеет разные настройки (OUTPUT/INPUT), а изменение любых настроек I2S вступает в силу только после **перезагрузки устройства**.


### USB (UAC2 Gadget)

- PureCore UAC2 — эмуляция USB Audio Class 2
- Поддержка PCM 2ch до 768kHz
- Поддержка DSD (DoP и Native через Alt-Setting 2)
- Режим **USB to I2S** — USB вход → I2S выход (только с ядром 6.1)
- Для поддержки native DSD и ASIO требуются проприетарные драйвера. Для тестирования предоставляются по запросу. Ведётся работа над собственными драйверами ASIO.  

### Переключение выходов

Через веб-интерфейс: тогл **I2S ↔ USB**
